# Windows Mobile 6.5 App Store

## Why Windows Mobile?
For many years, I've been using an old Samsung Omnia i900 as my MP3 player, running a custom Windows Mobile 6.5 ROM.
This operating system, although old and obsolete, still has a unique charm in a world dominated by Android.
As a student developer and a long-time fan of Windows Mobile (not Windows Phone), I decided to have some fun with it.

---

## The Project
For many years, I've browsed the web looking for games, applications, and utilities to bring my device to life and improve it. These searches left me with hundreds of .CAB files scattered across my hard drive.

The problem is twofold: these files are unorganized, and installing them requires connecting the phone, finding the right file, copying it over, and running it manually.

The idea here is to build a dedicated API, hosted on a server, that serves these installation files to a native Windows Mobile application. This app would display the list of available applications, let users search for them, download them, and install them directly. In short: a PlayStore for Windows Mobile (or a replacement for the now-defunct Windows Marketplace for Mobile).

This repository contains the native Windows Mobile 6 application.
